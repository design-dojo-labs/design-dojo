A FEW GOOD QUESTIONS

Before you begin.

Does the studio run on this website?+

This website introduces Design Dojo. The full studio runs on your machine because Java compilation, local files, SQLite, and your AI CLIs need a local server. Follow the setup commands above to start it.

Do I need an AI subscription?+

You can practice with the bundled problems without AI. Generation and reviews need an installed, authenticated Claude Code, Codex, or Gemini CLI. Use a supported subscription login or explicitly configure an API key in Settings.

How is my work evaluated?+

Each track has a 100-point rubric. Java reviews cover correctness, object modeling, design principles, extensibility, readability, edge cases, and tests. System design reviews cover requirements, APIs, data model, architecture, scalability, and trade-offs. AI feedback is a practice assessment, and results can vary.

Where does my practice data live?+

Sessions, reviews, and designs live locally in SQLite; Java workspaces and submission snapshots live on disk under ~/.lld-practice-studio. AI requests send the relevant work to your selected provider. Java code runs as your local user, so run only code you trust.
